# ValueSite

**무료 인터랙티브 IB 밸류에이션 대시보드**

> 기업가치를 계산하고, 가정을 검증하세요.

ValueSite는 밸류에이션 학습과 빠른 분석을 위한 무료 셀프서비스 도구입니다. 최소한의 재무정보를 입력하고 하나 이상의 평가 방법을 선택한 뒤, 주요 가정을 실시간으로 조정할 수 있습니다. 하나의 숫자를 정답처럼 제시하지 않고 하단·기준·상단의 가치 범위를 보여줍니다.

## 주요 기능

- 간편·고급 밸류에이션 모드
- 과거 실적과 추정치 입력표 (`A` = 실적, `E` = 추정)
- 고든 성장모형과 출구배수를 지원하는 DCF 엔진
- WACC, 영구성장률, 출구배수, 목표배수 실시간 조정
- 무위험수익률, 베타, ERP, 타인자본비용, 세율, 자본구조를 반영한 WACC 계산
- EV / EBITDA, P / E, P / B, EV / Revenue 밸류에이션
- 비교기업 데이터 입력 및 사분위수·중앙값·평균·최솟값·최댓값 자동 계산
- 선택 배수의 근거를 설명하는 규칙 기반 분석
- EV에서 주주가치로 이어지는 브리지와 주당가치 계산
- 선택한 방법을 한눈에 비교하는 가치범위 비교 차트(Football Field)
- 업종별로 흔히 쓰이는 방법 추천
- 비정상 입력과 경제적으로 취약한 가정을 점검하는 안전성 검사
- 가상 제조기업 데모 데이터
- LocalStorage 자동 저장
- 데스크톱·모바일 반응형 화면

## OpenDART 기업·재무정보 불러오기

OpenDART API 키는 Next.js 서버 라우트에서만 사용되며 브라우저 번들이나 API 응답에 포함되지 않습니다. [OpenDART 인증키 신청](https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do) 후 로컬에서는 `.env.local`, Vercel에서는 프로젝트의 Environment Variables에 `OPEN_DART_API_KEY`를 등록하세요. 키가 없거나 연결이 실패해도 직접 입력 기능은 그대로 작동합니다.

데이터 흐름은 다음과 같습니다.

1. 기업명 또는 종목코드 검색
2. 서버에서 OpenDART `corp_code` 매칭
3. 최근 3개년 재무제표 요청
4. 매출액, 영업이익, 당기순이익, 현금, 차입금, 자본 정규화
5. 사용자가 입력한 전망치를 유지하면서 과거 실적 자동 입력

연결재무제표(CFS)를 우선 사용하고 없을 때 별도재무제표(OFS)로 대체합니다. OpenDART 원 단위 금액은 내부 계산 정밀도를 유지한 채 십억원 단위로 변환합니다. 현재 주가, 희석주식수, 미래 추정치와 밸류에이션 가정은 자동으로 덮어쓰지 않습니다. 공시에서 안정적으로 찾지 못한 값은 비워 두고 직접 확인이 필요하다고 표시합니다.

기업 고유번호 ZIP/XML 목록은 24시간, 기업 개황은 24시간, 재무제표는 6시간 동안 서버 캐시를 사용합니다. ZIP 압축 해제에는 브라우저·서버 양쪽에서 검증된 소형 라이브러리 `fflate`만 추가했습니다.

### OpenDART 제한사항

- 계정 ID와 계정명은 기업별 공시 관행에 따라 다를 수 있습니다.
- 영업이익은 EBIT의 실무적 대용값으로 표시되며 엄밀한 조정 EBIT와 다를 수 있습니다.
- 차입금은 명확히 식별되는 단기·장기차입금과 사채만 합산합니다. 전체 부채를 차입금으로 사용하지 않습니다.
- OpenDART는 현재 주가와 애널리스트 전망치를 제공하지 않으므로 해당 값은 직접 입력해야 합니다.
- 자동 입력값도 원문 공시와 대조해야 하며 투자 판단을 보증하지 않습니다.

## 밸류에이션 방법

| 방법 | 주로 사용하는 경우 | 주요 한계 |
|---|---|---|
| DCF | 현금흐름을 비교적 합리적으로 예측할 수 있는 기업 | WACC와 최종가치 가정에 민감함 |
| EV / EBITDA | 제조업, 산업재, 통신, 자본집약적 업종 | 반복 CAPEX와 운전자본 소요를 충분히 반영하지 못할 수 있음 |
| P / E | 안정적인 순이익을 내는 상장기업 | 적자기업에는 의미가 없음 |
| P / B | 은행, 보험 등 재무상태표 중심의 금융회사 | 무형자산 중심 기업에는 적합성이 낮음 |
| EV / Revenue | 아직 이익은 없지만 빠르게 성장하는 기업 | 마진과 수익성 차이를 반영하지 못함 |
| 유사기업 비교 | 신뢰할 수 있는 상장 비교기업군이 있는 기업 | 비교기업 선정과 시장 상황에 크게 좌우됨 |

업종별 추천은 절대적인 처방이 아니라 **흔히 사용하는 방법**으로 안내되며, 사용자는 어떤 조합이든 자유롭게 선택할 수 있습니다.

## 기본 가정과 추정값

간편 모드에서는 세율, D&A, CAPEX, NWC 증감, WACC, 영구성장률에 명시적인 기본값을 적용합니다. 고급 모드에서는 각 항목을 직접 수정할 수 있습니다. 시스템이 추정한 값은 화면에 `기본 가정` 또는 `추정값`으로 표시합니다.

```text
NOPAT = EBIT × (1 − 세율)
UFCF = NOPAT + D&A − CAPEX − NWC 증감
```

## 주의사항

ValueSite는 교육 및 분석 목적으로만 제공됩니다. 투자 권유, 공정성 의견 또는 전문 실사의 대체물이 아닙니다. 결과는 사용자 입력과 가정에 따라 달라지며 실제 시장가치와 큰 차이가 날 수 있습니다.

## 2026-09-26 UX 개선 작업 요약

### 정보구조

- 최초 진입을 `내 기업 평가 시작`과 `샘플 분석 보기`로 분리했습니다.
- 본문 순서를 `기업·재무정보 → 평가 방법 → 주요 가정 → 결과 요약 → 상세 분석`으로 통일했습니다.
- 모바일은 `입력 / 가정 / 결과` 단계 화면으로 분리하고 고정 내비게이션을 제공합니다.
- 샘플 데이터, 사용자 입력, 시스템 기본 가정을 서로 다른 배지와 문구로 구분합니다.

### 계산과 검증

- 기존 DCF, 멀티플, EV 브리지 계산식은 유지했습니다.
- 종합 대표값을 선택 방법의 단순 평균에서 **중앙값**으로 변경했습니다.
- 마지막 평가 방법의 해제를 차단하고, WACC가 영구성장률 이하인 경우 DCF 계산을 중단합니다.
- 최종가치 비중 75% 초과 경고와 WACC × 영구성장률 민감도 표를 추가했습니다.
- 0 또는 음수인 비교기업 분모는 멀티플 통계에서 제외합니다.

### 입력과 접근성

- 숫자 입력에 천 단위 구분을 적용하고 모든 주요 필드에 접근 가능한 이름을 부여했습니다.
- 모바일 재무 입력과 비교기업 입력을 카드형 편집 화면으로 변경했습니다.
- 비교기업 추가, 삭제, 되돌리기, 초기화를 지원합니다.
- 평가 방법과 모드 선택에 `aria-pressed`, 키보드 포커스 표시를 적용했습니다.

- Next.js 프로덕션 빌드 통과
- 반응형 확인: 390 × 844, 768 × 900, 1440 × 1000
